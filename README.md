# DaerD (DD,ディーディー)

For animator controllers

GraphView ベースの AnimatorController エディタ。パラメーターの自動型変換、
トランジションのコピー＆ペースト、カスケードリネーム、コントローラー解析などを備えます。

## 主な機能

- ステートマシン / ブレンドツリーのグラフ編集（タブで複数コントローラーを開ける）
- Shift + スクロール — 表示中のレイヤーを上下に切り替え
- ステート検索 — ツールバーの検索欄からステート名・モーション名で全レイヤーを横断検索してジャンプ
- 解析 (Analyze) — 未使用パラメーター、壊れた条件、発火しない遷移、到達不能ステート、
  モーション未設定、Write Defaults 混在などを検出。多くの問題はワンクリックで修正可能。
  結果は独立した解析ウィンドウに表示され、グラフを編集しながら確認できる
  （ツールバーの「解析」または YozoLab > DaerD Analyzer から）
- クリップ一覧 — 参照している AnimationClip を独立ウィンドウで使用ステートつきに一覧表示
  （クリップ名で絞り込み・ステートへジャンプ・一括差し替え可能）
- クリーンアップ — .controller 内に残った未参照のサブアセット（ゴミ）を検出してワンクリックで削除
- Empty クリップ — コントローラーごとにプレースホルダー用クリップを指定すると、新規ステートに自動で設定され、
  解析の「穴埋め」修正でモーション未設定のステートや空のブレンドツリースロットを一括補完
- DBT ガジェット — Float パラメータの指数スムーズ化（AAP Smooth）や、
  加算・減算・乗算・AND / OR / NOT・しきい値・リマップといった毎フレーム演算を行う
  Direct ブレンドツリーの仕掛け（WD ON の 1 ステート + ネストしたツリー）を自動生成。
  パラメーターパネルの「Add」メニューから。生成されるクリップ・ツリーは
  コントローラーのサブアセットとして保存され、Direct ブレンドツリーのみのレイヤーは
  レイヤー一覧に「DBT」バッジで表示。コントローラー解析が DBT の健全性
  （WD OFF のステート、ウェイトパラメーター未設定 / 欠落 / 非 Float）も検査
- オブジェクトトグル — GameObject の ON/OFF クリップとその配線をウィザードで自動生成。
  シーン上のオブジェクトをドロップするだけで Animator ルートからの相対パスを計算し、
  「新規レイヤー（Bool パラメーター + OFF/ON 2 ステート + 即時遷移）」と
  「Direct ブレンドツリー（Float パラメーターで駆動する 1D ツリーを 1 レイヤーに集約）」の
  2 方式から選択可能。パラメーターの新規作成 / 既存流用、初期状態 ON、対象ごとの反転
  （トグル ON で非表示）にも対応。生成されるクリップは .controller と同じフォルダに
  .anim アセットとして保存。コントローラー概要（何も選択していないときのインスペクター）の
  「オブジェクトトグル…」またはパラメーターパネルの「Add」メニューから
- 日本語 / English 表示切り替え（Preferences > Yozolab > daerD、既定はシステム言語に追従）
