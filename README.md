# DaerD (DD,ディーディー)

For animator controllers

GraphView ベースの AnimatorController エディタ。パラメーターの自動型変換、
トランジションのコピー＆ペースト、カスケードリネーム、コントローラー解析などを備えます。

## 主な機能

- ステートマシン / ブレンドツリーのグラフ編集（タブで複数コントローラーを開ける）
- Shift + スクロール — 表示中のレイヤーを上下に切り替え
- ステート検索 — ツールバーの検索欄からステート名・モーション名で全レイヤーを横断検索してジャンプ
- 遷移の優先順位 — Animator は 1 つのステートから出る遷移を**リスト順に評価**します
  （条件を満たした最初の 1 本が勝つ）。ステートを選ぶとその全遷移が評価順に並び、
  ドラッグで並べ替えられます。Entry / Any State の遷移も同じ一覧から扱えます。
  行にマウスを乗せるとグラフ側の該当エッジが色付き、Solo された遷移に阻まれて
  評価されない遷移は Mute と同じ赤で表示されます
- 解析 (Analyze) — 未使用パラメーター、壊れた条件、発火しない遷移（条件同士が矛盾していて
  成立しえないものを含む）、到達不能ステート、Solo の消し忘れ、Any State の自己割り込み
  （Can Transition To Self の付けっぱなしで遷移先が頭から再生し直される定番の罠）、
  モーション未設定、Write Defaults 混在などを検出。多くの問題はワンクリックで修正可能。
  結果は独立した解析ウィンドウに表示され、グラフを編集しながら確認できる
  （ツールバーの「解析」または YozoLab > DaerD Analyzer から）
- クリップ一覧 — 参照している AnimationClip を独立ウィンドウで使用ステートつきに一覧表示
  （クリップ名で絞り込み・ステートへジャンプ・一括差し替え可能）
- クリーンアップ — .controller 内に残った未参照のサブアセット（ゴミ）を検出してワンクリックで削除。
  あわせて、使用中なのに Project ウィンドウに露出しているサブアセット
  （Behaviour の非表示フラグが失われたもの）を検出し、削除せず非表示に戻せます
- Empty クリップ — コントローラーごとにプレースホルダー用クリップを指定すると、新規ステートに自動で設定され、
  解析の「穴埋め」修正でモーション未設定のステートや空のブレンドツリースロットを一括補完
- DBT ガジェット — Float パラメータの指数スムーズ化（AAP Smooth）や、
  加算・減算・乗算・除算・逆数・AND / OR / NOT・しきい値・リマップ・桁分解といった
  毎フレーム演算を行う Direct ブレンドツリーの仕掛け（WD ON の 1 ステート + ネストしたツリー）を自動生成。
  除数が動く範囲を宣言できるなら Reciprocal (Ranged) / Divide (Ranged) が最善です — 除数を
  1 以上へ持ち上げて厳密側だけで割るので、**逆数の 240 上限もルックアップ表の誤差もありません**。
  **符号付き乗算 / 除算**は Multiply (Signed) / Divide (Signed) が担当します — Direct の重みは
  負をゼロに切り捨てるので素の乗除算は正数専用ですが、符号付き版は入力を正負の半分に分けて
  4 象限を合算するため、どの符号の組み合わせでも正しく計算します（レンジが縛るのは入力だけで、
  積は範囲外へ出られます）。
  **各ガジェットの所要フレーム数は値によらず一定**で、連鎖すると加算されます — 1 フレーム
  （四則・論理・リマップ・三角関数・LUT・atan2）、2（逆数・符号付き乗算）、3（除算）、
  4（符号付き除算）、5（桁分解）、Buffer は指定した N。同じ入力から深さの違う 2 枝が
  出ると別フレームの値を見ることになるので、浅い側に差分だけ Buffer を挟んで揃えます。
  一定速度で追従する線形スムーズ、前フレームからの経過秒を返すフレーム時間、
  モーションタイムでカーブを引く sin / cos / tan も選べます（逆数・除算・フレーム時間・
  三角関数はコントローラー末尾に専用の補助レイヤーを追加します）。
  平方根・逆平方根・log2・exp2 は窓（入力レンジ）を宣言するだけの 1 フレームのテーブルで、
  サンプルは関数に合わせて配置します（平方根と対数は等比、指数は等間隔 — どちらもその方が
  誤差が全域で一定になる）。累乗は底も指数もパラメーターにできる唯一の形で、
  log2 → 符号付き乗算 → exp2 の 4 フレーム（中間レンジは宣言した 2 つから自動で決まります）。
  任意のカーブを描いて 1D ブレンドツリーの区分線形 LUT にベイクする LUT (Curve) と、
  方向ベクトルから角度を「周」単位（0..1）で返す atan2（2D FreeformDirectional の方向 LUT。
  結果をそのまま sin / cos ガジェットへ渡せます）は、補助レイヤーなしでツリー内に収まります。
  バッファ (Buffer / Delay) は入力をちょうど N フレーム遅らせるコピー — ブレンドツリーの計算は
  1 段ごとに 1 フレーム遅れるため、段数の異なる分岐が同じパラメーターの別フレームの値を
  見てしまう「時系列ズレ」を、浅い側にバッファを挟んで補正できます。
  パラメーターパネルの「Add」メニューから。生成されるクリップ・ツリーは
  コントローラーのサブアセットとして保存され、Direct ブレンドツリーのみのレイヤーは
  レイヤー一覧に「DBT」バッジで表示。コントローラー解析が DBT の健全性
  （WD OFF のステート、ウェイトパラメーター未設定 / 欠落 / 非 Float）も検査
- オブジェクトトグル — GameObject の ON/OFF クリップとその配線をウィザードで自動生成。
  シーン上のオブジェクトをドロップするだけで Animator ルートからの相対パスを計算し、
  「新規レイヤー（Bool パラメーター + OFF/ON 2 ステート + 即時遷移）」と
  「Direct ブレンドツリー（Float パラメーターで駆動する 1D ツリーを 1 レイヤーに集約）」の
  2 方式から選択可能。パラメーターの新規作成 / 既存流用、初期状態 ON、対象ごとの反転
  （トグル ON で非表示）にも対応。生成されるクリップは .controller と同じフォルダに
  .anim アセットとして保存。コントローラー概要（何も選択していないときのインスペクター）の
  「オブジェクトトグル」またはパラメーターパネルの「Add」メニューから
- 巡回同期（Async Sync / パラメーター圧縮） — 指定したパラメーター群を
  「インデックス + 型別値チャンネル」という少数の同期パラメーターに時分割多重。
  VRChat の約 0.3 秒の同期周期を利用し、ローカル側の巡回ステートが Parameter Driver で
  値を順番に載せ、リモート側が AnyState デコーダーで書き戻す。同期コストのプレビュー付き
  （コントローラー概要またはパラメーターパネルの「Add」から）。
  インデックスは既定の「自動」でパラメーター数に応じて Int / Bool の安い方を選択
  （同ビット数なら同期パラメーター 1 個で済む Int）。
  Float チャンネル数は 1〜8 で調整可能 — 1 ステップで複数の Float を同時に運び、
  スロット数を減らして 1 周を高速化（チャンネル 1 本につき同期 8 bit）。
  「巡回の順序と重み」エディタで巡回順をドラッグで明示指定でき、各パラメーターに
  ×1〜×4 の重みを設定可能 — ×N はそのパラメーターが 1 周に取る枠の数で、できるだけ
  等間隔に配置されます。**速度ではなく 1 周の配分**なので、全員を上げても何も変わらず
  （共通倍率は自動で正規化）、1 つを上げると 1 周が伸びて他が遅くなります。
  行ごとに実際の更新間隔（〜秒ごと）と巡回全体のプレビュー（F → B → F → I …）を表示。
  他のスロットで間隔を空けきれない重みは実効値に丸めて警告。対象一覧には検索窓付き。
  「変わった瞬間に送りたい」は重みではなく**リクエスト**の役目です。
  IsLocal や巡回同期自身が生成したパラメーターは対象に選べません。
  生成 State にはコントローラーの Empty クリップを自動割り当て（ステップ時間はクリップ長で正規化）。
  同期リクエスト（Req）を有効にしたパラメーターは、順番を待たずに送れます — ローカルの
  Bool フラグが立つと巡回は 1 ステップぶん**寄り道**してそのスロットを送り、
  離れた場所へ巡回を戻します。位置を戻すので巡回が止まらず、寄り道どうしは連続しないので、
  どれだけ叩かれても 1 周は最大 2 倍まで（ウィザードに秒で表示）。
  リモート初期化フラグ（Ready）を有効にすると、そのクライアントが全スロットを 1 度以上
  受信し終えた時点で 1 になるローカル Bool を生成 — リモートには装着者へ問い合わせる手段が
  無いので、これがその代わりになります。各スロットの受信ビットは一度立ったら落ちないため、
  周回の途中で入っても最大 1 周でラッチし、判定に時間窓もマージンも要りません。
  装着者側は最初から 1（自分の値はどこにも行っていないため）なので、
  「初期化を終えたリモート」は `Ready && !IsLocal` と書けます。同期ビットの増加は 0 で、
  費用はスロット数ぶんのローカル Bool と監視レイヤー 1 枚。
  同期ズレ疑いフラグ（Stale）は、**1 周のあいだに全スロットが届かなかったとき 1、届いた周で 0**
  になるローカル Bool。判定は「1 周に 1 回だけ送られるスロット」が回ってきた瞬間なので、
  タイマーもマージンも要らず、リクエストで 1 周が伸びても誤検知しません。
  受信ビットを落とすのは監視レイヤー自身で、読む側と落とす側が同じレイヤーに入るため競合しません
  （マーカーのステップはまだ 1 ドウェル丸ごと残っているので、次のスロットは数百フレーム先）。
  そのようなスロットが無い巡回（全スロットが複数回送られる／全部リクエスト対象）では作れないので、
  黙って落とさずエラーで拒否します。周の途中で入ったリモートはその周のあいだ 1 になるため、
  「初期化中」と区別したいときは Ready と組み合わせます。
  グループを指定すると、**同時に変わるべき値がリモートで必ず同時に代入されます**。
  デコーダは実パラメーターではなく影パラメーター（`Hold/`）へ受け、**全メンバーが届いた時点で
  1 個の Parameter Driver が一括コピー**するので、同時性がタイミングではなく構造で保証されます
  （1 つのドライバのエントリは同じフレームで走るため）。揃わなかった周はコミットせず、
  **ちぎれた新しい状態ではなく、揃った 1 周前の状態**のまま次の周で治ります。
  同じステップに載るパラメーターは元々一緒に届くのでグループは不要で、その場合は警告を出します
  （グループが要るのは型が違う・チャンネルが足りないなどで同じステップに入れられないとき）。
  同期ビットの増加は 0。
  1 周の所要時間・優先パラメーターの更新間隔・追加コスト 0 で入るスロット数・
  圧縮しても減らない構成・パペット操作で駆動されている対象などを警告表示。
  生成レイヤーは保存され、レイヤー一覧に「SYNC」バッジ表示＋ウィザードから同じレイヤーを再生成
- VRC / NDMF 連携 — パラメーターストア（VRC Expression Parameters アセット **または
  Modular Avatar の MA Parameters コンポーネント**）をコントローラーに明示的に割り当てて、
  ビット予算表示・synced/saved トグル・差分プレビュー付き同期を利用可能。
  自動検出は「検出」ボタンを押したときの完全一致のみ（ギミック用 Animator でも誤爆しない）。
  Expressions Menu の組み込みエディタ（パンくず・コントロール編集・パラメーター警告）、
  Play Audio / Locomotion / Layer Control / Playable Layer Control / Pose Space の編集、
  Behaviour のステート間コピー&ペースト（インスペクターでタイトルをクリックして複数選択し、
  選択中は Ctrl+C / Ctrl+V で選択した Behaviour だけをコピー&ペースト）、
  ステート複数選択時の Behaviour 一括編集（種類 + インスタンス名で束ねて表示し、
  編集は同じ Behaviour を持つ全ステートへ反映。未所持ステートへの一括追加 / 全削除 / 全ペーストも可能）、
  PhysBone 系パラメーターファミリーの一括リネーム。
  すべて VRChat SDK 不在でもコンパイル・動作可能（該当機能のみ非表示）
- **C# Recipe（AnimatorController ⇄ C# 変換）** — コントローラー全体または選択レイヤーを、
  それを再構築する編集可能な C#（DaerD Authoring API）へエクスポート。API は
  [AnimatorAsCode](https://github.com/hai-vr/av3-animator-as-code) V1 準拠の方言
  （`NewState` / `WithAnimation` / `TransitionsTo(x).When(go.IsTrue())` /
  `Drives` / `DrivingRemaps` …、パラメーターは型付きハンドル）。生成コードは
  冒頭に API チートシート付きで、**AI に渡してそのまま編集してもらえる**形式。
  クリップ / マスク参照は Recipe アセット（ScriptableObject）のフィールドに
  自動代入され、インスペクターで D&D 差し替え可能 — **コードに GUID は一切入りません**。
  出力は **partial class を分けた 2 ファイル**：`<Name>.Generated.cs` はエクスポートのたびに
  丸ごと作り直される「機械側」、`<Name>.cs` は**あなた（や AI）の Build() で DaerD は
  二度と上書きしません**（実行されるのはこちら）。エクスポート → 整形 → 生成 →
  コントローラー編集 → 再エクスポート、というループで整形が消えないための分割で、
  再エクスポートの変更は Generated 側の git diff にきれいに出ます。
  Recipe アセットの「エクスポート側と比較」は両者が宣言する内容（IR）を突き合わせ、
  整形が意味を変えていないことを保証します — 読み方ではなく**出来上がる物**の比較なので、
  ループやヘルパーで書き直しても通ります。
  Recipe の「生成」で対象コントローラーへ適用（部分 Recipe は同名レイヤーをその場で置換、
  exclusive はコントローラー全体を所有）、「検証」でコードと実物の乖離をレポート。
  Recipe 所有レイヤーはレイヤー一覧に「C#」バッジ表示。
  `c.Raw(controller => …)` で DaerD / Unity の全 API へのエスケープハッチ、
  `c.AsyncSync()` からは巡回同期をフル設定 + ウィザードには無い**明示スケジュール**
  （`Schedule("Hue","Outfit","Hue","Tail")`）まで指定可能。
  `c.Gadgets("DBT")` は DBT ガジェット（加算・乗算・符号付き乗算・リマップ・スムーズ・
  逆数・除算・符号付き除算・フレーム時間・三角関数・LUT・atan2・桁分解・バッファ）を
  C# で並べて 1 レイヤーに生成 — 引数はパラメーターハンドルでも文字列でも渡せます。
  ビルダーは各パラメーターが入力から何フレーム遅れているかを追跡していて、
  `FramesBehind("Out")` で書いている最中に読めます（Buffer の段数を手で数えずに計算できる）。
  同じ信号が別の深さで 1 つのガジェットに入ると、両方の年齢と挿すべき Buffer 呼び出しを
  名指しで報告します。無関係な 2 信号の年齢差は報告しません（フレーム時間 × レートのような、
  そもそも揃える対象が無い組み合わせ）。`.RequireAligned()` を付けると報告ではなく生成拒否に
  変わります。生成のたびにそのレイヤー・補助レイヤー・
  出力パラメーターの名前空間（`Out` と `Out/…`）を掃除してから作り直すので、
  何度 Generate しても積み上がりません。エクスポートしたコードのうち、
  ツリーがそのまま出て読みづらいガジェットレイヤーだけをガジェット呼び出しに
  書き換える、という使い方ができます。
  ループで書ける単純作業の量産・巡回同期の精密調整・AI による調整が主用途。
  正しさはラウンドトリップで担保（エクスポータは実際にビルダー API を実行しながら
  その呼び出し列を記録する方式 — 出力コードと検証済み動作が構造的に一致）
- レイヤーのコピー&ペースト（コントローラー跨ぎ・参照パラメーター自動追加・フレーム引き継ぎ）と
  レイヤー / ブレンドツリーテンプレート（パラメーターリマップ付きインポート）
- ステートのレイヤー間コピー&ペースト — Ctrl+C したステートは、レイヤーを切り替えて Ctrl+V すれば
  そのレイヤーへ貼り付けられます（Behaviour・コピーした範囲内のトランジションに加え、
  Entry / Exit / AnyState との接続も貼り付け先レイヤーの各ノードへ張り直し。
  別コントローラーへ貼るときは参照パラメーターを自動追加し、ブレンドツリーは複製）。レイヤー設定の
  「ステートを貼り付け」からは、切り替えずに他レイヤーへ直接貼り付け。
  貼り付け先に同名ステートがある場合のみ連番を付与。サブステートマシンは対象外
  （レイヤーごと移したい場合は「レイヤーをコピー」を使用）
- フレーム / ノートのレイヤー間コピー&ペースト — Ctrl+C / Ctrl+V（右クリックメニューや
  インスペクターの「Copy Frame」「Copy Note」からも）。クリップボードはレイヤー参照を持たないため、
  別レイヤー・別コントローラーへ貼り付け可能。ステートと一緒に選択してコピーすると
  相対位置を保ったまま一緒に貼り付けられます
- リパスツール — 階層変更で壊れたクリップのバインディングをスキャン・一括書き換え、
  Hierarchy の変更を追従する自動リパス（クリップ一覧の「リパス」から）
- QoL — 雛形付き一括トランジション生成（Seeded）、I / O / P・F / A（選択 / 全体をフレーム）・
  Ctrl+F（検索欄へ）・Ctrl+A・Ctrl+Shift+A ショートカット、**矢印キーで隣のステートへ移動**、
  **M / T で配線**（M = 選択を遷移元としてマーク、T = マーク済み → 選択へ接続。
  マークが無いときの T はクリック順に連結するので、2 個選んで T だけで繋がります）。
  これらのキーは **Preferences > Yozolab > daerD の「キーボードショートカット」で
  変更・個別に無効化**できます（グラフとインスペクターは別枠なので、同じキーに別の役割を
  割り当てられます）、
  検索候補の ↑↓ 選択、
  遷移条件のマウスホイール操作（比較 / true・false のポップアップ上で反転、しきい値の上で
  増減。1 刻み・Ctrl 併用で 0.1 刻み。Int は常に 1 刻み）、
  クリップの Loop Time 一括切り替え、等間隔整列、パラメーターの複製 / コピー / 参照リマップ /
  クリーン削除、AAP バッジ表示
- 日本語 / English 表示切り替え（Preferences > Yozolab > daerD、既定はシステム言語に追従）。
