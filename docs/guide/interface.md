# 画面構成

DaerD ウィンドウは、上部のツールバーと複数のパネル、中央のグラフで構成されています。

## 全体レイアウト

<!-- 画像を差し込む場合はここに。例:
![DaerD の画面構成](/images/interface-overview.png)
画像は docs/public/images/ に置き、/images/... で参照します。 -->

```
┌───────────────────────────────────────────────────────────┐
│ タブバー（開いているコントローラー）                        │
├───────────────────────────────────────────────────────────┤
│ ツールバー / パンくず（現在のステートマシン階層）           │
├──────────────┬─────────────────────────────┬──────────────┤
│ レイヤー      │                             │ Inspector    │
│ パラメータ    │        グラフビュー          │ （選択中の    │
│ （左パネル）  │   （ステート・遷移・BlendTree） │  詳細編集）   │
│              │                             │ プレビュー    │
└──────────────┴─────────────────────────────┴──────────────┘
```

## 各部の役割

### タブバー
開いているコントローラーがタブとして並びます。クリックで切り替え、閉じることもできます。タブごとに最後に見ていたレイヤーが記憶されます。

### パンくず（ブレッドクラム）
サブステートマシンや BlendTree の中に入ると、現在の階層がパンくずとして表示されます。クリックで上の階層へ戻れます。

### レイヤーパネル
コントローラーのレイヤー一覧です。選択でグラフの表示対象を切り替え、追加・並べ替え・ウェイトの調整などを行えます。

### パラメータパネル
コントローラーのパラメータ一覧です。追加・削除・リネーム・型変更を行えます。型変更やリネームは、参照している条件へ自動的に反映されます（[パラメータ型の自動変換](/features/parameter-conversion) / [カスケードリネーム](/features/rename)）。

### グラフビュー
中央のメイン領域です。ステート・トランジション・サブステートマシン・BlendTree を編集します。フレーム（グループ枠）やメモもここに表示されます。

### Inspector パネル
グラフで選択したステート・トランジション・パラメータなどの詳細を編集します。

### プレビュー
選択中のステートのモーションをプレビューできます。Unity の Animation ウィンドウと連携し、編集中のクリップを確認できます。
