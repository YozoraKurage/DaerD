# フレームとメモ

大きなコントローラーほど、ステートの塊が何を表しているのかが分かりにくくなります。DaerD では**フレーム**と**メモ**でグラフを視覚的に整理できます。

## フレーム（グループ枠）

フレームは、ノードの背後に描かれるコメント／グループ用の枠です。関連するステートをまとめて囲み、ラベルを付けることで「このまとまりは何か」を明示できます。

- フレームはグラフ（ステートマシンビュー）単位で保持されます。
- レイヤーではなく、表示中のステートマシンごとに管理されます。

## メモ（付箋）

メモは、ノードの間に自由に置ける付箋のようなノートです。補足説明や TODO などを、グラフ上に直接書き残せます。

## フレームの複製

フレームは、**中に含まれるステート・メモ・完全に内側にあるトランジションごと複製**できます。よく似た構成を別レイヤーやステートマシンで再利用したいときに、まとめて複製できます。

## 別ステートマシンへの持ち込み

フレームやメモは、あるステートマシンから別のステートマシンへ引き継ぐこともできます（フレームの継承）。ステート構成を移し替えるようなリファクタリングでも、整理情報を保ったまま作業できます。

## アニメーションへの影響はなし

フレームとメモは編集を助けるための付加情報で、コントローラー専用データとして保存されます。ランタイムのアニメーション挙動には一切影響しません（[よくある質問](/guide/faq) も参照）。
