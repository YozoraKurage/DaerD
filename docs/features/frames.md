# フレームとメモ

大きなコントローラーほど、ステートの塊が何を表しているのかが分かりにくくなります。DaerD では**フレーム**と**メモ**でグラフを視覚的に整理できます。

## フレーム（グループ枠）

フレームは、ノードの背後に描かれるコメント／グループ用の枠です。関連するステートをまとめて囲み、ラベルを付けることで「このまとまりは何か」を明示できます。

- グラフの右クリック → **Frame & Note → Create Frame**（選択を囲む **Create Frame Around Selection** もあります）
- フレームは表示中のステートマシンごとに管理されます（レイヤー単位ではありません）。

### フレームの操作

右クリックメニューから次を行えます。

| 項目 | 内容 |
| --- | --- |
| **Rename Frame** | 改題（`F2` でも可） |
| **Frame Color** | プリセットから色を変更 |
| **Move Nodes With Frame** | フレームを動かしたときに中身も一緒に動かすか（既定は ON） |
| **Fit To Contents** | 中身にぴったり合うようにサイズを調整 |
| **Select Contents** / **Select States Inside** | 中身をまとめて選択 |
| **Lock Frame** | ロック。移動・リサイズ・改題・削除ができなくなります |
| **Duplicate Frame** | 複製（下記） |

## メモ（付箋）

メモは、ノードの間に自由に置ける付箋のようなノートです。補足説明や TODO などを、グラフ上に直接書き残せます。`F2` またはダブルクリックで編集できます。

## フレームの複製

フレームは、**中に含まれるステート・メモ・完全に内側にあるトランジションごと複製**できます。よく似た構成を再利用したいときに、まとめて複製できます。

## レイヤーをまたぐコピー＆ペースト

フレームとメモは `Ctrl+C` / `Ctrl+V` でコピーできます（右クリックメニューやインスペクターの **Copy Frame** / **Copy Note** からも）。

クリップボードの内容は**元のレイヤーへの参照を持たない**ため、別のレイヤーにも、別のコントローラーにも貼り付けられます。

ステートと一緒に選択してコピーすると、**相対位置を保ったまま**一緒に貼り付けられます。

::: tip レイヤーごと持っていく場合
レイヤーをコピーすると、フレームとメモもそのレイヤーに付いていきます（[レイヤー操作](/features/layers)）。
:::

## アニメーションへの影響はなし

フレームとメモは編集を助けるための付加情報で、コントローラー専用データとして保存されます。ランタイムのアニメーション挙動には一切影響しません（[よくある質問](/guide/faq) も参照）。
