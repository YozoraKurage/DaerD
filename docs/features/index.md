# 機能一覧

DaerD の主な機能をまとめます。各項目のリンクから詳細ページに移動できます。

## 編集

- [グラフ編集](/features/graph-editing) — ステート・トランジション・サブステートマシンの編集、ショートカット、一括生成、整列、ステート検索、複数コントローラーのタブ表示。
- [BlendTree 編集](/features/blendtree) — 専用ビューでの編集。ネスト対応、テンプレート、パラメータリマップ。
- [レイヤー操作](/features/layers) — レイヤーとステートのコピー＆ペースト（コントローラー跨ぎ）、テンプレート、バッジ。
- [フレームとメモ](/features/frames) — グループ枠と付箋でグラフを整理。レイヤーをまたいでコピー可能。

## リファクタリング

- [パラメータ型の自動変換](/features/parameter-conversion) — 型変更に合わせて参照条件を自動で書き換え。差分プレビュー付き。
- [カスケードリネーム](/features/rename) — パラメータ名・クリップ名の変更を関連箇所へ波及。PhysBone の一族リネームにも対応。
- [トランジションのコピー＆ペースト](/features/transitions) — 設定・条件の再利用と、複数選択での一括編集。
- [クリップとリパス](/features/clips) — 参照クリップの一覧・一括差し替え・壊れたバインディングの修正。

## 検証と整理

- [コントローラー解析](/features/analysis) — 未使用パラメータ・不正な条件・到達不能ステート・Write Defaults 混在などを検出し、一括修正を提供。
- [クリーンアップ](/features/cleanup) — `.controller` に残った未参照サブアセットの削除。

## 生成ツール

- [DBT ガジェット](/features/dbt-gadgets) — Direct BlendTree で毎フレーム演算する仕掛けを自動生成（加算・乗算・スムーズ・三角関数・LUT ほか）。
- [オブジェクトトグル](/features/object-toggle) — GameObject の ON/OFF クリップと配線をウィザードで生成。
- [巡回同期](/features/async-sync) — 複数パラメータを少数の同期パラメータへ時分割多重するパラメータ圧縮。
- [C# Recipe](/features/recipe) — コントローラーを編集可能な C# へ変換し、コードから再生成。

## VRChat

- [VRC / NDMF 連携](/features/vrchat) — パラメータストア（VRC Expression Parameters / MA Parameters）、ビット予算、Expressions Menu エディタ、VRC Behaviour の編集。
