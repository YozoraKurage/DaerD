# 機能一覧

DaerD の主な機能をまとめます。各項目のリンクから詳細ページに移動できます。

## 編集

- [グラフ編集](/features/graph-editing) — ステート・トランジション・サブステートマシン・BlendTree の編集、複数コントローラーのタブ表示、ステートの複製など。
- [BlendTree 編集](/features/blendtree) — BlendTree を専用ビューで編集。ネストした BlendTree にも対応。
- [フレームとメモ](/features/frames) — ノードを囲むグループ枠と付箋メモでグラフを整理。フレーム単位の複製にも対応。

## リファクタリング

- [パラメータ型の自動変換](/features/parameter-conversion) — パラメータの型変更に合わせて参照条件を自動で書き換え。差分プレビュー付き。
- [トランジションのコピー＆ペースト](/features/transitions) — トランジションの設定・条件をまとめて再利用。
- [カスケードリネーム](/features/rename) — パラメータ名や AnimationClip 名の変更を関連箇所へ波及。

## 検証

- [コントローラー解析](/features/analysis) — 未使用パラメータ・不正な条件・到達不能ステートなどを検出し、一括修正を提供。

## 一覧表

| 機能 | 概要 |
| --- | --- |
| GraphView ベースの編集 | 応答性の高いグラフでステート/遷移を編集 |
| マルチタブ | 複数コントローラーを同時に開く |
| パラメータ型の自動変換 | 型変更時に条件を自動書き換え（プレビュー付き） |
| トランジションのコピペ | 設定・条件をまとめてコピー、ドメインリロード耐性あり |
| カスケードリネーム | パラメータ名・クリップ名の変更を波及 |
| フレーム / メモ | グループ枠・付箋でグラフを整理 |
| BlendTree 編集 | ネスト対応の専用ビュー |
| コントローラー解析 | 問題検出と一括修正 |
